# 猫咪调解室双场景设计

## 统一美术

角色沿用橘猫主持者、穿橄榄绿的虎斑和系灰蓝围巾的小羊。面部去掉统一粗描边，身体比例和坐姿接近日常会客。两幅图都用暖纸上的水粉笔触，左窗提供柔光，家具以胡桃木、织物和接触阴影承重。奶油底、深绿控件和衬线标题承接原站界面。

| 画面 | 旧版问题 | 新构图与职业识别 |
| --- | --- | --- |
| 法院 | 对称远景里，三个头像近似贴在桌沿上 | 视角拉到前排。法官穿深绿法袍，左右来访席错深，角色手势和目光随发言席变化。酒红过道、卷宗和木槌形成仪式感 |
| 教师办公室 | 粗边线与均匀颗粒把人物、家具和空间压在同一层 | 斜侧的会客三角。左边老师握笔，较远的虎斑伸手解释，靠前的小羊收拢双手倾听。软木板连接笔记、差异和下一步 |

首轮办公室试稿的写实毛发和布料细节明显重于原法庭。定稿使用较简的五官、暖纸肌理和相近的肤色明度，再用同一批角色参考制作法庭。法庭使用卷宗和酒红，办公室使用记录板和灰蓝。

## 教师流程

| 现有界面阶段 | 教师表达 | 画面 |
| --- | --- | --- |
| 进入与陈述 | 分别表达 | 空椅按到场状态显示。老师前倾，停笔听来访者 |
| 单方提交 | 等待另一位表达 | 第一张纸条落在桌面，另一位到场时显示老师低头记录 |
| 真实分析 | 梳理想法 | 两张示意卡归入「在意的点」和「理解差异」，纸条内容保持私密 |
| 报告已保存 | 一起回顾、沟通记录 | 老师朝板面伸手，双方放松姿态，出现「一起试试」卡片 |
| 本人选择建议 | 下一步可以试试 | 记录板收束为「我想试试」，表示本页的个人选择 |

报告中的共同点以「可以一起确认的地方」呈现。补充便签可贴上和移除，仅保留当前页面状态。法院番茄仍落在本地判词牌上。两者都沿用本地反馈语义。

## 换景分镜

创建页和 Qoder Sites 单人体验复用同一个选择器。点选后，旧画面略收暗，墨绿幕片横移，完全遮住画面时换上另一套职业服装与布景，最后揭幕。全程 1.35 秒。跳过后回到选中的单选按钮，系统启用减少动态效果时直接换图。选中的模式随单选项立即更新，房间创建仍由表单提交触发。

## 图层与素材

使用内置 ImageGen 生成原创水粉画，随后压缩为 1536×768 WebP。旧素材继续保留。所有会随业务状态更新的纸条、归类卡、卷宗、法槌和番茄都由 SVG 与 CSS 绘制。

- 办公室四帧以靠窗斜侧会客为主体，使用旧庭审底图的暖纸和水粉，以及品牌橘猫、虎斑和小羊作为设计参考。局部关键帧依次保留空椅、停笔倾听、低头记录和抬手引导。
- 法院五帧使用同一原画体系，要求法袍、居中的抬高法官席、左右分隔桌位与酒红过道。局部编辑依次保留 A 方表达、右侧空席、B 方表达、低头阅卷和抬头宣读。
